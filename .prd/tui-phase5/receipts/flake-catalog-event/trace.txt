   129  /// Whether a request carrying the bearer to `url` may go through a proxy that
   130  /// `HTTPS_PROXY`, `HTTP_PROXY` or `ALL_PROXY` names.
   131  ///
   132  /// Over https the proxy is handed a `CONNECT` and a TLS stream it cannot read,
   133  /// and an endpoint on the internet may be reachable no other way. A cleartext
   134  /// request -- which the bearer rule allows only to loopback -- goes to the proxy
   135  /// as written, key and prompt, and reqwest exempts no loopback host from one.
   136  /// Anything that is not plainly https gets no proxy, so a mistake here costs a
   137  /// direct connection and never the key. Upstream loads no proxy at all: it
   138  /// never calls `initDefaultProxies` (`vercel-labs/fx@c1db9191 src/`).
   139  pub(crate) fn may_use_a_proxy(url: &str) -> bool {
   140      ParsedUrl::parse(url.trim()).is_some_and(|parsed| parsed.scheme == "https")
   141  }
