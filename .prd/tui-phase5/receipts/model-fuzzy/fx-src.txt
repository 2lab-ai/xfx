## Fuzzy: containsWordStartSubsequence, M:415-436; isIdWordStart, M:438-447
- M:420-426  the word's first alphanumeric must equal (case ignored) an id byte that starts an id
         word -- the first such position.
- M:428-434  the rest of the word's alphanumerics in order after it, any distance apart.
- M:416-417 "Anchoring the first letter keeps short words from matching scattered letters across
         unrelated models."
- M:440-447  a word start is an alphanumeric byte at index 0, after a non-alphanumeric byte, or
         where `isDigit(previous) != isDigit(byte)` -- letters into digits or back. A change of case
         is not one (no case test in the function). "`gpt-4o` has the words `gpt`, `4`, and `o`"
         (M:438-439). All of it is std.ascii: a byte outside ASCII is never alphanumeric, so it is
         punctuation.
