## fx's count, read at the pin

fx counts a line a display unit at a time (`displayUnitAt`,
`src/core/shared/display_width.zig:234-263@481104fd`): an ASCII byte; an
RGI emoji sequence whole, two cells (`:246-247`); a variation base and its
U+FE0E (its own width) or U+FE0F (two cells, `:251-260`); else one code
point, `runeWidth` (`:275-282`):

- 0 for NUL, C0 and C1 (`:276-277`);
- 0 for a zero-width continuation (`isZeroWidthContinuation`, `:409-420`):
  `isCombining` (`:400-407`: U+0300-036F, U+1AB0-1AFF, U+1DC0-1DFF,
  U+20D0-20FF, U+FE20-FE2F, U+FE00-FE0F), the skin-tone modifiers
  (`emoji_modifier_ranges`, `unicode_display_data.zig:250-252@481104fd`),
  U+200B-200F, U+202A-202E, U+2060-206F, U+FEFF, U+E0001-E007F,
  U+E0100-E01EF;
- 2 for `wide_ranges` (`unicode_display_data.zig:40-164`, U+302E in
  `0x2FF0-0x303E` at `:81`) or `emoji_presentation_ranges` (`:166-248`, the
  regional indicators `0x1F1E6-0x1F1FF` at `:204`);
- 1 for everything else.

fx's grid takes each unit at that width (`engine.zig:1187-1191@481104fd`)
and joins a unit of no cells to the cell before it (`:1193-1197`). Neither
file moved between `c1db9191` and `481104fd` but for `decodeUtf8Sequence`
(malformed UTF-8 only); `unicode_display_data.zig` is the same bytes.

`fx_rune_width.py` reads the four range tables out of
`unicode_display_data.zig@481104fd` itself and applies `runeWidth`: fx's
count of every scalar, independent of xfx's port
(`src/markdown/display_width.rs`).
