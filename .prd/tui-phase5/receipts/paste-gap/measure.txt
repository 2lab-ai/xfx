# paste_xfx.py against a real xfx: one paste `ESC[200~ early-paste-text ESC[201~ <body> CR ESC[201~`,
# its body a `K<7 digits>` token every max(32, size/256) bytes and 0xff between (dropped by the
# decoder with no event). Sizes include the outer markers. Fields:
#   paste_submitted      the paste's own CR was read as a key and submitted a prompt by itself
#   typed_bytes          what the submitted prompt held after `early-paste-text`: bytes that reached
#                        the decoder as typed keys (pty, outer), or the paste's own text (tmux, below)
#   first_key_token      the first token read as a key -- where the delivery that carried the
#                        embedded marker ended; null = nothing after the marker reached the keys
#   dropped_before_keys  body bytes before that token, dropped as input behind the paste
#   warning              `! input: Input that arrived right after the paste was ignored.` on screen
# Modes: pty   = xfx on a raw pty, the paste one blocking write to the master;
#        tmux  = a private tmux server (-L paste-gap-<pid>, -f /dev/null), `load-buffer` +
#                `paste-buffer -p -r` of the text between the outer markers;
#        outer = the same pane, attached by a tmux client on a pty this script writes the whole
#                paste to: a terminal that does not strip the marker, in front of tmux.
# Binaries: base = a832f4d7's debug build (banner v0.1.0-a832f4d), head = ea2b8a60's (v0.1.0-ea2b8a6),
# each checked by the revision embedded in it. tmux 3.7b, Darwin 25.6.0.
